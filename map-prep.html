Map prep

HomeWikiMap prepCharacter builderNPC builderTown builderTreasure plannerChange LogClass Commands

Paint a map's walls, water, doors and lighting here, at your own pace, then take the file to Discord with the image. Nothing you load or paint on this page is uploaded anywhere; it stays in your browser until you download the file.

  1. Load your map image and tell the page how many columns and rows the grid has.
  2. Paint terrain the way /tgmap terrain does, and pick the whole map's light level.
  3. Download the terrain file (a small .json).
  4. In Discord run /tgmap upload_gridless or upload_gridded with your image and add the file as terrain_file.

1 · Map image

The same numbers you give upload_gridded. Adjust them until the lines sit on the printed grid.

Gridless: the grid is fitted to the image and centred, exactly as upload_gridless does.

2 · Light

The whole map's light level. Torches and lamps painted above light up their surroundings when the map is dim or dark. Fog of war is not saved here; it starts fresh when the encounter does.

3 · Terrain

Load a map image to start, or open a terrain file and paint on a blank grid.
 

4 · Save

The file will be named map_bright_15x20.json.

Open a file you saved earlier to keep editing it. Use the same grid size in the upload command.

The map as a picture

Your map image with the terrain painted on and the grid lines drawn, at the image's own size. The labelled version adds the column letters and row numbers around the edge, as Discord shows them. Hidden hazards (traps) are left off, so either picture can be shared with players. Load an image first.
