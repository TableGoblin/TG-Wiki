Privacy Policy

Last updated September 14, 2026

This policy explains what Table Goblin sees and stores while it runs your Pathfinder Second Edition game, and why. The short version: the bot only accesses what your table sends it in order to do its job, and it doesn't watch your server beyond that.

01What We Collect

Table Goblin's access is scoped to what a command or interaction actually needs to run. In the normal course of operating the service, that includes:

  • Discord identifiers — your user ID, and the server (guild) and channel IDs the bot operates in — used to keep one table's data separate from another's and to route responses to the right place.
  • Command and interaction input — the slash commands you run and the options you provide, so the bot can carry out the action you asked for.
  • Content you create through the bot — character sheets, campaign and encounter state, battle-map layouts, loot, and settlement data entered via Table Goblin's own commands, so it can be stored and shown back to your table.

Table Goblin does not read the general message traffic of a server or channel it is in. Outside of the commands and interactions above, the one exception is the optional AI GM feature described below.

02The AI GM Feature

Opt-in only. This section applies only if your table specifically enables the AI Game Master feature. If it isn't turned on, none of this applies to your server.

The AI GM feature lets Table Goblin take part in a game's narrative — describing scenes, voicing NPCs, and responding to what the party does in character. For it to do that, once a table turns it on, the bot reads messages posted in the specific in-character channel(s) that table designates for the feature, so it has the conversation's context to work from.

Those messages, along with the relevant character and campaign context Table Goblin already stores, are sent to the third-party AI service that powers this feature in order to generate the bot's in-character responses. They are used for that purpose only — to hold up the table's side of the conversation — and are not used to build advertising profiles or sold to anyone.

A table can disable the AI GM feature at any time, which stops the bot from reading that channel going forward.

03How We Use Information

  • To run the command or feature you invoked and return the correct result.
  • To persist your table's own game state (characters, campaigns, encounters, loot, maps) between sessions so it's there the next time you play.
  • To power the AI GM feature, only for tables that have opted in.
  • To diagnose and fix problems with the bot itself.

04Storage and Retention

Game data is stored in Table Goblin's own database, keyed to the Discord server and user IDs it belongs to, for as long as your table continues to use the bot. If a server removes Table Goblin, or a table asks us to delete its data, we will remove the associated records within a reasonable time.

05Sharing of Information

We do not sell your data or your table's data. Information is shared only where it's needed to operate the service:

  • Discord — as the platform the bot runs on, per Discord's own Terms of Service and Privacy Policy.
  • Our AI service provider — only for tables that have enabled the AI GM feature, and only the channel content and context needed to generate a response, as described above.
  • Hosting infrastructure — the servers Table Goblin's database and code run on.

06Data Security

We take reasonable steps to protect the information Table Goblin stores, but no method of storage or transmission is completely secure, and we can't guarantee absolute security.

07Your Choices

You can stop Table Goblin's access to your data at any time by removing it from your server, or disable the AI GM feature specifically without removing the bot entirely. To request deletion of your table's stored data, contact us using the details below.

08Children's Privacy

Table Goblin is intended for use on Discord, which requires users to meet Discord's own minimum age requirements. We do not knowingly collect information from anyone below that age beyond what Discord itself provides as part of normal platform use.

09Changes to This Policy

We may update this policy as Table Goblin's features change. The "Last updated" date above reflects the most recent revision.
