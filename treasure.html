Treasure planner

HomeWikiMap prepCharacter builderNPC builderTown builderTreasure plannerChange LogClass Commands

A whole level's treasure for your party, rolled from GM Core's Party Treasure by Level on the official treasure tables (the same as /tgm treasure), then split across the encounters you plan to run so each one is worth about the same.

  1. Set the party's level and size, and how many encounters the level's treasure should cover.
  2. Choose whether uncommon or rare items may turn up; anything else is rolled again.
  3. Press Roll treasure. Press 🎲 beside an item to roll it again; change the encounters to split it again.
  4. Copy as text or Print the plan. It is kept in this browser.
